# Copilot-Mimic

## Project Description
Copilot-Mimic is a gaming-focused social media mockup designed to emulate the core experience of a community-driven content platform for gamers. The application brings together social discovery, shared updates, community circles, and engagement interactions in a streamlined interface tailored for online gaming culture.

The project focuses on creating a polished experience for:
- finding teammates and squads
- sharing gameplay moments and clips
- discovering gaming communities
- browsing trending game-related content
- engaging with post interactions such as likes, comments, and saves

This project was built as a front-end prototype using HTML, CSS, and JavaScript, with a strong emphasis on UI design, responsive layout, and interactive social feed behavior.

## Installation
1. Clone the repository to your local machine.
2. Open the project folder in VS Code.
3. Navigate to the project root.
4. Start a local web server from the project directory using Python:

```bash
python -m http.server 8000
```

5. Open the browser and visit:

```text
http://localhost:8000
```

## Setup Instructions
1. Ensure you have Python installed on your machine.
2. From the project root, run the local server command above.
3. If needed, use a browser refresh to view updates after editing files.
4. Edit the front-end files in the following locations:
   - HTML: `index.html`
   - CSS: `CSS/style.css`
   - JavaScript: `JS/script.js`
