# Copilot-Mimic
Recreate a already popular social media platform using copilot

## Instagram (For Games)
The idea is too make a instagram mimic which tries to mainly focus on online gaming communities for things like

-Finding teammates 

-Sharing clips

-News in Gaming

## Tools
The stack used for this project for MVP is HTML/CSS/JS for a web development perspective on the process. The bulk of the work done using ai is using copilot built into copilot while ChatGPT ive always used for things like removing white backgrounds from SVG elements for web design.
